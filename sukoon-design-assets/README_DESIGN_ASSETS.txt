SUKOON DESIGN ASSETS
=====================
Pulled directly from the shipped index.html, so these exactly match production.
Provided in both SVG (vector, editable) and PNG (raster, transparent background)
in case your upload target doesn't accept SVG.

sukoon-logo-mascot.svg / .png
  Main mascot/logo, full size. Claymorphic shading baked in.

sukoon-message-badge.svg / .png
  Small chat-bubble version of the mascot (30px use case).

sukoon-typing-indicator.svg / .png
  Full "typing" scene: mascot + notepad + quill. The SVG has animation class
  names (typing-cloud, typing-quill, typing-glow, etc.) but the actual
  @keyframes live in index.html's <style> block. The PNG is a static frame.

sukoon-header-art-optimized.svg / sukoon-header-art.png
  Vector/raster versions of the header background scene (mountains/sun/
  stupa/flags). SVG is 1.1MB / 5,089 paths — kept for reference/editing.

sukoon-header-art.webp
  The actual production header background (152KB, smallest option).

sukoon-color-palette.svg / .png
  Swatch sheet of all 25 CSS custom-property tokens with hex values.
